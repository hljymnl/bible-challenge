# 📖 我爱读圣经 · 一年 7 遍挑战

> **每一天,让神的话语成为你的粮食。**
> 一年读完 7 遍圣经 —— 每天 23 章,52 天一遍,全年 7 遍,绝无压力。

## ✨ 功能

- 🎯 **每日必读** — 自动计算今天该读哪卷哪章(1189 章 ÷ 52 天 = 每天 23 章)
- ✅ **打卡追踪** — 每天读完点打卡,进度环 + 连续天数,本机保存
- 📊 **进度总览** — 第几天 / 第几遍 / 累计已读章数 / 年度完成率
- 🔄 **自动换遍** — 52 天读完一本自动进入下一遍,一年正好 7 遍
- 🔊 **朗读经文** — 一键朗读今日经文(内置浏览器语音,可切换音色)
- ⚡ **高效方法** — 内置 8 条读经效率锦囊(番茄钟 / 碎片拆分 / 固定时段…)

## 🚀 使用

1. 直接用浏览器打开 `index.html` 即可(完全离线可用)
2. 线上版: **https://hljymnl.github.io/bible-challenge/**

## 👨‍👩‍👧 声音设置(晓晓 / 云希)

默认使用浏览器内置中文语音。若要启用 **Edge 晓晓 / 云希** 的神经语音(音质更好),需配置 Azure Speech 服务:

1. 在 [Azure 门户](https://portal.azure.com) 创建 Speech 服务,拿到 **Key** 和 **Region**
2. 打开 `js/tts.js`,填入:
   ```js
   TTS.azure.key = "你的Key";
   TTS.azure.region = "eastasia"; // 你的区域
   ```
3. 保存后用浏览器打开,朗读即自动使用晓晓/云希神经语音
